- 分支 `webpack5-vue2`。删除了半成品 webpack/ 目录（用户手动删除）与 vue.config.js、postcss.config.js。
- 新建 `webpack/webpack.common.js`（工厂函数，extractCss 参数区分 dev/prod 样式策略）、`webpack.dev.js`（devServer 9527 + mock 挂载 + HMR）、`webpack.prod.js`（原 chainWebpack 分包策略 chunk-libs/chunk-elementUI/chunk-commons + runtimeChunk single）、`webpack/InlineRuntimePlugin.js`（自写，替代与 hwp5 不兼容的 script-ext-html-webpack-plugin，内联 runtime.js）。
